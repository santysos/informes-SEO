El charango es un instrumento de cuerda andino con una afinación particular que requiere precisión para lograr el sonido auténtico y claro característico de este instrumento. Si eres principiante y estás aprendiendo a afinar tu charango, este blog te guiará paso a paso en el uso de un afinador para que puedas obtener el mejor sonido posible.

Conociendo la Afinación del Charango

El charango se afina en una configuración específica que es crucial para su sonido único. La afinación estándar del charango es:

Primera cuerda (la más cercana al suelo cuando tocas): Mi (E)
Segunda cuerda: La (A)
Tercera cuerda: Mi (E)
Cuarta cuerda: Do (C)
Quinta cuerda: Sol (G)

Es importante recordar que la afinación de la primera cuerda (Mi) y la tercera cuerda (Mi) son una octava más baja que las otras cuerdas. Asegúrate de que tu afinador esté configurado para detectar estas notas de manera precisa. Conoce mas detalles sobre El Proceso de Afinación del Charango: Técnicas para un Sonido Perfecto

Uso del Cifrado Americano

Para afinación, el cifrado americano se usa para identificar las notas musicales. Aquí están las notas básicas que necesitas conocer:

A - La ; B - Si ; C - Do ; D - Re ; E - Mi ; F - Fa ; G - Sol

Cuando uses un afinador, asegúrate de leer las notas de izquierda a derecha en el orden del cifrado americano. Por ejemplo, si el afinador muestra Re (D) cuando deberías ajustar a Mi (E), es necesario afinar el charango hasta que el afinador marque la nota correcta.

Cómo Afinar el Charango con Afinador

Preparación Inicial: Asegúrate de que tu afinador esté encendido y configurado correctamente para la afinación de cuerda que necesitas. Si estás usando un afinador de teléfono móvil, ten en cuenta que la interfaz puede variar, pero los principios básicos son los mismos.

Afinación de las Cuerdas:

  • Primera Cuerda (Mi - E): Toca la cuerda y ajusta el afinador para que marque Mi (E). Si el afinador muestra Re (D), ajusta la cuerda hasta que se muestre Mi (E). Si muestra Fa (F), necesitarás desajustar.
  • Segunda Cuerda (La - A): Realiza el mismo proceso para esta cuerda, ajustando hasta que el afinador indique La (A).
  • Tercera Cuerda (Mi - E): Asegúrate de que esta cuerda esté afinada una octava más baja que la primera cuerda, utilizando el afinador para alcanzar Mi (E).
  • Cuarta Cuerda (Do - C): Ajusta hasta que el afinador muestre Do (C).
  • Quinta Cuerda (Sol - G): Finalmente, ajusta esta cuerda hasta que el afinador indique Sol (G).

Sostenido y Bemol: Si el afinador muestra un sostenido (♯), significa que la cuerda está afinada ligeramente alta, por lo que deberás aflojarla. Si muestra un bemol (♭), la cuerda está afinada demasiado baja, así que ajusta para subir el tono.

    Consejos para Afinar el Charango en el Afinador con Precisión

    • Afinadores Recomendados: Aunque puedes usar afinadores en el móvil, un afinador específico para instrumentos como el charango puede ofrecer una mayor precisión y ser más práctico.
    • Verificación: Después de ajustar cada cuerda, vuelve a verificar su afinación para asegurarte de que no se haya desajustado durante el proceso.
